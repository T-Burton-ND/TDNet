# Release and Operations History Source

The 2026-08-17 release-status report and the visible repository Git history document the transition from retrospective research artifacts to weekly scientific prediction and postgame publication.

## Specific claims

As of the 2026-08-17 report, the corrected-F6 wide bundle had 34 learned estimators and two equal-weight ensembles; corrected HPS had completed 13,920/13,920 trials; and the F0–F8 scientific refit contained 54/54 cells. The four 2025 regeneration packages later documented in the same release materials each contained 17 poll weeks, 16 prediction weeks, and zero poll failures. Through-2025 packages were operational dry runs; through-2024 checkpoints supplied the actual 2025 holdout.

The visible commit sequence starts with public release on 2026-08-13, then readiness/release preparation, Zenodo artifacts, graphics, and discrepancy tracking. From 2026-08-28 through 2026-09-23, commits add the immutable scientific weekly pipeline, Week 0 package and postgame figures, weekly prediction/result archives, cumulative performance and Vegas baselines, scientific performance figures, and expanded tracking. This Git history does not establish the project’s true start or complete pre-August planning.
