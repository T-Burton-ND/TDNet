# Source Archive Index

This page explains where TDNet’s prose documents went when the project documentation was consolidated into the LLM wiki.

## Archived originals

The 43 tracked Markdown files formerly under `docs/` are preserved verbatim under `.llm-wiki/source-archive/docs/`. Their directory layout mirrors the former `docs/` paths; each original `name.md` is now `name.md.txt` so the wiki graph treats these as source records rather than duplicate wiki pages. For example, the former `docs/publication_2026/CONFIRMATORY_PROTOCOL.md` is now `.llm-wiki/source-archive/docs/publication_2026/CONFIRMATORY_PROTOCOL.md.txt`.

These are source snapshots, not new policy decisions. Relative links inside an archived file are preserved as written and refer to the original project layout. Use the linked wiki summaries for current interpretation and navigation.

## What remains under `docs/`

The remaining tracked `docs/` files are machine-readable data, reproducibility fixtures, manifests, and publication/style assets. They remain at their project paths because code, release metadata, or rendering workflows use them directly. Private ignored working material under `docs/blog_assets/` was left in place.
