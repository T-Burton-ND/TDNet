# 2025 holdout examples

This directory is reserved for curated, public-facing examples produced by
TDNet models trained before the 2025 holdout season.  They are retrospective
examples, not live forecasts and not the current 2026 model outputs.

Only reviewed figures and compact provenance may be committed here.  Raw CFBD
records, derived game-, team-, player-, prediction-, ballot-, and market-level
tables, model checkpoints, and generated manuscript tables remain excluded
from the public repository.  To reproduce results, supply your own data access
and run the documented reproduction workflow.
